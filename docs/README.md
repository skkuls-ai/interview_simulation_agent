## 문서를 읽는 법

- 본문의 「미정」·「(제안)」은 기획 단계 표시다. 구현에서 해결·채택된 내용은 문서마다 있는 「결정 결과」 절을 우선한다(01 9절, 02 9절, 03 3절, 04 8절, 05 0·8절).
- 초기 기획(`PLAN.md`)과 충돌하면 01~08을 따른다. 꼬리질문, 평가자 병렬 실행, 검증 에이전트, 검증 실험은 1차 구현 범위에 없다.
- `archive/`는 지난 설계 자료다.

## 구현 현황 (2026-10-01)

- 완료: 서류 분석, 질문 5개 생성(자기소개 고정, 인성 은행 선택, 기술 생성), 음성 면접(시선 측정 포함), 서버 음성 변환·삭제, 평가와 인용 검증, 피드백 화면.
- 한계: 세션은 서버 메모리에만 있어 재시작 시 사라지고, 로그인과 이어하기가 없으며, 「다시 연습하기」는 새로 평가하지 않을 수 있다. LLM 판정은 실행마다 조금씩 다를 수 있다.
- 발표는 사전 녹화한 시연 영상으로 한다.
