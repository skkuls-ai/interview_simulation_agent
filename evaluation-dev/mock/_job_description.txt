[데모용 가상 직무기술서] 실제 회사와 관계없는 시연용 문서입니다.
회사: 브라이트런
직무: AI Agent·LLM 애플리케이션 엔지니어 (신입)

직무 목적
사내 문서와 고객 문의 데이터를 근거로 답하는 AI Agent를 설계·구현하고, 응답 품질을 측정해 지속적으로 개선한다.

주요 업무
1. 문서 수집·전처리와 RAG 인덱스 구축 (청킹, 임베딩, 벡터 DB 적재)
2. 검색 품질 평가 데이터셋 구축과 검색 지표(Recall@k 등) 측정
3. LangGraph 기반 멀티 에이전트 워크플로우 구현과 에이전트 간 입출력 스키마 설계
4. FastAPI 서비스 API 개발, 로그 수집과 응답 품질 모니터링
5. 현업 담당자와 요구사항을 정리하고 진행 결과를 공유

필요 지식
- 임베딩과 벡터 검색의 원리, 청크 크기와 검색 품질의 관계
- LLM 응답 품질 평가 방법 (정답셋 기반 평가, LLM 평가자의 한계)
- 프롬프트 인젝션 등 LLM 서비스 보안 위험

필요 기술
- Python과 SQL을 이용한 데이터 처리
- LangChain·LangGraph, 벡터 DB(ChromaDB 등) 활용
- FastAPI 기반 API 개발
- Docker 기반 서비스 배포와 운영

직무 수행 태도
- 결과를 수치와 근거로 설명하는 태도
- 모르는 부분을 빠르게 확인하고 동료와 공유하는 태도
