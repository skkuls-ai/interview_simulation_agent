직무: AI Agent·LLM 애플리케이션 엔지니어 (신입)

회사 소개
브라이트런은 제조·에너지 기업의 사내 문서와 고객 문의 데이터를 활용해 업무를 자동화하는 AI Agent를 만드는 B2B 스타트업입니다.

담당 업무
- LangChain·LangGraph 기반 멀티 에이전트 워크플로우 설계와 구현
- 사내 문서(PDF·매뉴얼) 기반 RAG 파이프라인 구축과 검색 품질 개선
- FastAPI 기반 AI 서비스 API 개발과 프론트엔드 연동
- LLM 응답 품질 평가 기준 수립과 개선 실험

자격 요건
- Python 기반 프로젝트 개발 경험
- LLM API(Gemini, OpenAI 등)를 활용한 애플리케이션 개발 경험
- RAG 또는 벡터 데이터베이스 활용 경험
- 팀 프로젝트에서 역할을 나누고 협업한 경험
- LLM 응답 품질을 정량적으로 평가하고 모니터링한 경험

우대 사항
- LangGraph 등 에이전트 프레임워크로 멀티 에이전트를 구현한 경험
- 지식 그래프 또는 하이브리드 검색 경험
- Docker 등을 이용한 서비스 배포 경험
- 데이터 전처리와 품질 검증 파이프라인 구축 경험

인재상
- 문제를 스스로 정의하고 근거를 바탕으로 해결하는 사람
- 동료와 적극적으로 소통하며 결과를 함께 만드는 사람
- 새로운 기술을 빠르게 학습해 실무에 적용하는 사람
